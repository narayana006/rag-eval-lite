# Sync and offline use

Notes sync between devices every 30 seconds while the app is open. Sync uses an end-to-end encrypted channel, so the server never sees note contents.

## Offline edits

Edits made offline are stored on the device and uploaded the next time a connection is available. Up to 500 offline changes are kept per device.

## Conflicts

When the same note is edited on two devices before they sync, Orbit Notes keeps both versions. The later edit becomes the main note and the earlier one is saved as a conflict copy in the same folder.

## Storage limits

Each workspace on the Team plan gets 50 GB of attachment storage. A single attachment can be at most 200 MB.

# Sharing

A note can be shared with a link or with named people. Link sharing is off by default and must be switched on by a workspace owner.

## Guest access

Guests can view and comment on notes shared with them, but cannot create notebooks. A workspace can invite up to 25 guests at no extra cost.

## Export

Any notebook can be exported as Markdown or PDF. Exports include attachments and are delivered as a zip file.

## Deleting notes

Deleted notes go to the trash and stay there for 30 days. A workspace owner can restore a note from the trash or delete it permanently.
